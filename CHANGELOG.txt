1. WHAT IS ALREADY IMPLEMENTED
========================================================

Personal chats
  - 1-on-1 dialogs, group chats, broadcast channels
  - Replies, forwards with attribution, emoji reactions
  - Typing indicator, read receipts, per-message read-by
  - Scheduled messages, message search in chat, search by date
  - File uploads (images/video/audio/documents), translation

Groups & channels
  - Create / join (invite link) / leave / update, roles owner/admin/member
  - Role permissions, promote/demote, remove members
  - Channel admins with granular rights, subscribe/unsubscribe
  - Group invites (create/revoke), public/private chats, discover showcase
  - Join requests for private groups (request/approve/reject + system-chat notify)
  - Per-member permission overrides, bans/mutes with expiry

Stories / calls / music
  - Stories: create/view/like/reaction/reply/stats, share, replace
  - Audio/video calls, WebRTC + video integration, call history
  - Personal music playlist, add audio from messages

Account & social
  - Register/login (password, OTP, QR, Google OAuth), sessions per device
  - Contacts (add/rename/delete, import), blocked users
  - Premium (promos, status emoji, stickers), referrals, bots + webhooks
  - Saved messages, archive, pinned chats, chat folders (Sputnik pack)
  - Data export (JSON), admin DB backup (sqlite)

Sputnik ideas pack (app/routes/spav2/sputnik.py, /api.v2/api/sputnik/*)
  - Edit history, message trash (move/restore/clear), SSRF-safe link preview
  - Albums + reorder + bulk lookup, video circles (1-60s), deduped views
  - Custom stickers (upload/favorite/from-message/send, canvas editor),
    chat folders, drafts, profile banners, profile media grid, discover
  - Cloud 2FA password + app-lock PIN (bcrypt) + email recovery
  - Frontend: self-mounting nav, formatting toolbar, gestures, album grid,
    round player, spoiler reveal, scheduled/sticker composer buttons

Security (Sputnik v0.60-v0.64 class fixes applied)
  - Chat participation checks on pin/forward/dismiss
  - Presence honors privacy_last_seen; /u/<username> requires auth
  - Upload path traversal closed; per-account brute-force lockout

========================================================
2. KNOWN PROBLEMS (TO FIX)
========================================================

[!] Tests run against the FILE database instance/kiselgram.db (conftest URI
    override happens after engine creation) and truncate all tables per test.
    Never run pytest against production data. Fix: bind the engine after the
    config override or use a separate test database file.
[!] tests/test_auth.py, tests/test_chats.py fail on the pristine tree
    (legacy SPA expectations). Parts of test_spav2_admin.py and
    test_spav2_search.py fail the same way.
[!] tests/test_client_api.py hangs order-dependently at
    test_activate_premium_already_premium (passes standalone).
[!] RateLimiter._store and _ACCOUNT_FAILURES are in-memory: they persist
    across tests in one pytest process and do not work across workers
    (Redis/DB needed for production multi-worker).
[!] require_csrf() exists but is opt-in; enabling globally breaks
    cookie-authenticated clients and tests.
[?] mypy reports repo-wide patterns (db.Model dynamic base, missing stubs).
